## About

아이디어를 실제로 사용할 수 있는 형태까지 구현하는 제품 개발자입니다.
Android와 크로스 플랫폼 앱을 중심으로, 사용자 경험에서 출발한 구조와
오래 유지할 수 있는 시스템을 설계합니다.

최근에는 **Kotlin Multiplatform 기반의 공통 UI·도메인 설계**와
**LLM을 활용한 개발 워크플로 자동화**에 집중하고 있습니다.

## How I work

- **Start with the experience** — 사용자가 마주하는 화면과 흐름에서 설계를 시작합니다.
- **Build for change** — 기술의 새로움보다 유지보수성과 팀의 학습 비용을 함께 봅니다.
- **Automate repetition** — 반복되는 수작업은 문서화하거나 자동화합니다.
- **Close the loop** — 작은 기능도 배포, 관찰, 개선의 사이클 안에서 다룹니다.

> 작게 시작하고, 빠르게 검증하고, 반복은 자동화합니다.
