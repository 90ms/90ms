### About

제품의 아이디어를 실제로 사용할 수 있는 형태까지 구현하는 개발자입니다.
Android와 크로스 플랫폼 앱을 중심으로 일하며, LLM을 활용한 자동화와
개발 생산성을 높이는 도구를 함께 실험하고 있습니다.

요즘은 다음 주제에 집중하고 있습니다.

- Kotlin, Jetpack Compose 기반의 모바일 아키텍처
- Kotlin Multiplatform을 활용한 공통 도메인 설계
- Flutter를 활용한 빠른 제품 검증
- LLM 기반 콘텐츠·업무 자동화
- 디자인 시스템과 재사용 가능한 UI 구조

### How I work

- 사용자가 마주하는 화면과 흐름에서 설계를 시작합니다.
- 기술의 새로움보다 유지보수성과 팀의 학습 비용을 함께 봅니다.
- 반복되는 수작업은 문서화하거나 자동화합니다.
- 작은 기능도 배포, 관찰, 개선의 사이클 안에서 다룹니다.

> 작게 시작하고, 빠르게 검증하고, 반복은 자동화합니다.
